# 🎓 AI Face Recognition Attendance System

A Streamlit attendance system using DeepFace and ArcFace.

## Features
- Face recognition from uploaded images
- Automatic attendance with date and time
- Duplicate attendance prevention per day
- Attendance table and CSV download
- Portable relative project paths

## Technologies
Python, Streamlit, DeepFace, ArcFace, OpenCV, Pandas

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Student registration
Keep `students.csv` with `roll_no,name` columns and place reference images inside matching folders under `database/`.
